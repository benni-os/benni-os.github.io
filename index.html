Execution Workflow Story

Intent → Plan → Agents → Execution → Evidence

PHASE 01 // INTENT

Operator Intent Parsing

The operator submits a high-level goal. Benni Master OS normalizes the payload and calculates SHA-256 byte-level hashes.

PHASE 02 // PLAN

Run Ledger & Checkpoint Lock

The Control Plane generates a multi-step Run Ledger, establishes atomic checkpoints, and locks scope boundaries to prevent drift.

PHASE 03 // AGENTS

JARVAS-2 Swarm Mesh Dispatch

Specialized subagents (Codebase Researcher, Content Swarm, Build Shipper) execute subtasks in parallel background processes.

PHASE 04 // EXECUTION & POLICY GATE

NEMESIS Policy Gate Check

NEMESIS Security Gateway verifies HMAC signatures, single-use token consumption, and human confirmation matching.

PHASE 05 // EVIDENCE

Evidence Return & Financial Settlement

Results are committed immutably to Git with cryptographic signatures, trace IDs, and MONOMO event revenue attribution.

TRUST & GOVERNANCE

Built for Full Auditability and Human Control

Benni OS never executes destructive mutations silently. Every critical action requires explicit, payload-bound approval with HMAC signature verification.

Byte-Integrity Hashes

SHA-256 computed on normalized canonical payloads before human review.

Single-Use Tokens

Approval tokens expire in 5 minutes and cannot be reused across calls.

Zero Log Leakage

Production logs print only byte counts and 8-character hash prefixes.
